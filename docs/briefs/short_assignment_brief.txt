IRAQ DISCOVERY DATA COLLECTION — SHORT BRIEF

Collect and normalize a complete, API-ready dataset of places, events, services, and companies across Iraq for the Iraq Discovery mobile app, covering 8 categories (Accommodation, Cafes & Restaurants, Events, Tourism, Government Offices, Services, Companies, Shopping). Prioritize Erbil first (Batch 1: 10–25 records per category), then Baghdad (Batch 2), then expand to other cities. For each record capture universal fields (name, address, lat/lng, phone, website, opening hours, price range, rating, images, accessibility, source/license) plus category-specific attributes (e.g., star rating & amenities for hotels, cuisine types for restaurants, event dates, industry for companies). Normalize all data (deduplicate by name+coords, geocode missing coordinates, standardize names/addresses/tags), validate against the JSON schema (data/schemas/iraq_discovery.schema.json), and deliver incrementally as JSON + CSV with a README and acceptance checklist. Front-end needs filter metadata and suggested UI component types (chips, toggles, dropdowns) to display filters for each category—see DATASET_README.md for full schema and filter mappings. Provide sample Postman endpoints and mock JSON responses so the team can begin front-end integration immediately.
